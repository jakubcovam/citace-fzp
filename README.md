# 📚 Citace a reference bez stresu

Průvodce citováním a rešerší pro studenty, kteří píšou závěrečnou práci. Vznikl pro studenty **Fakulty životního prostředí ČZU v Praze**, ale většina obsahu poslouží komukoli, kdo píše bakalářskou nebo diplomovou práci.

🔗 **Web:** https://jakubcovam.github.io/citace-fzp/

## Co v průvodci najdete

- **Kde hledat odborné zdroje:** hlavní vědecké databáze (Scopus, Web of Science, Google Scholar a další), oborové a open access zdroje, české knihovny a repozitáře závěrečných prací
- **Odkazy pro studenty FŽP ČZU:** UIS, Moodle, studentský intranet a univerzitní knihovna na jednom místě
- **Jak v databázích správně hledat:** tipy pro efektivní rešerši
- **Jak citovat v textu** a **citování krok za krokem ve Wordu**
- **Vzory citací podle ČSN ISO 690** pro nejčastější typy zdrojů
- **Pravidla akademického psaní**, včetně toho, jak se vyhnout plagiátorství a predátorským časopisům
- **Kontrolní seznam před odevzdáním:** zaškrtnuté položky si prohlížeč zapamatuje, takže se k seznamu můžete vracet
- **Časté dotazy**

## Technické informace

Celý průvodce je jediný soubor `index.html` bez dalších závislostí a bez sběru dat. Stav kontrolního seznamu se ukládá pouze lokálně ve vašem prohlížeči (localStorage) a nikam se neodesílá.

Web je hostovaný na **GitHub Pages**. Každá změna nahraná do větve `main` se na webu automaticky projeví během několika minut.

Pro lokální prohlížení stačí stáhnout `index.html` a otevřít ho v prohlížeči.
